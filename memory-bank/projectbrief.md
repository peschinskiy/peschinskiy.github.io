# Project Brief: peschinskiy.github.io

## Overview
Personal technical blog "pure++" by Igor Peschinskiy, a software engineer at Yandex focusing on backend development, data processing, and infrastructure support.

## Core Purpose
- Share technical insights and explorations in software engineering
- Focus on synergies and interconnections between technologies
- Explore real-world examples at the intersection of different domains
- NOT tutorials or subjective opinions, but technical exploration

## Target Audience
- Software engineers interested in backend development
- Developers working with C++, functional programming, GIS
- Tech professionals exploring performance optimizations
- Engineers interested in cross-domain software development

## Technical Requirements
- **Platform**: Jekyll static site hosted on GitHub Pages
- **Theme**: Minimal Mistakes theme (v4.27.3)
- **Domain**: https://peschinskiy.github.io
- **Performance**: Fast loading, mobile-responsive design
- **Accessibility**: Clean, readable code blocks without horizontal scroll
- **SEO**: Proper meta tags, sitemap, analytics integration

## Content Scope
- Backend development insights
- GIS and mapping technologies
- C++ and systems programming
- Functional programming concepts
- Performance optimization techniques
- Infrastructure and data processing

## Success Metrics
- Content quality over quantity
- Proper technical accuracy
- Good reader engagement
- No horizontal scroll issues on code blocks
- Fast page load times
- Mobile-friendly experience

## Constraints
- GitHub Pages hosting limitations
- Jekyll static site generator requirements
- Minimal Mistakes theme structure
- Personal time availability for content creation
